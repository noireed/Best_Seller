# DART 공시·재무정보 연동

금융감독원 Open DART에서 종목에 대응하는 회사 고유번호, 공시 목록, 단일회사 전체 재무제표를 조회합니다. 거래 주문이나 OpenAI 호출 없이 독립적으로 실행할 수 있습니다.

## 설정 및 실행

[Open DART](https://opendart.fss.or.kr/)에서 인증키를 신청한 뒤 기존 `.env`에 다음 항목을 추가합니다. 실제 키는 커밋하지 않습니다.

```dotenv
DART_ENABLED=true
DART_API_KEY=
DART_DB_PATH=data/dart_cache.db
DART_CACHE_SECONDS=3600
DART_DAILY_BUDGET=500
```

```bash
python -m app.dart_cli --symbol 005930 --output data/dart.json
python -m app.main --once --scan-only
```

키 미설정·오류·일일 예산 소진 시 상태와 이유를 반환합니다. DART만 실패한 경우 기존 가격·뉴스 분석을 유지합니다. 설정을 끄려면 `DART_ENABLED=false`를 사용합니다.

## 수집과 계산

- 고유번호 ZIP 파일로 종목코드와 회사 고유번호를 연결합니다. 고유번호 캐시는 24시간 유지합니다.
- 최근 550일의 정기공시(A)를 페이지별로 조회합니다. 대형 기업의 지분공시 등으로 재무보고서 조회가 잘리지 않도록 공시 유형을 제한합니다. 10페이지를 넘어가면 잘린 목록으로 판단하지 않고 수집 실패로 처리합니다.
- 12월 결산 회사의 사업·반기·분기보고서를 지원합니다. 최신 회계기간을 선택한 뒤 해당 기간의 최신 정정본을 선택합니다. 예전 사업연도 정정본을 최신 분기보다 우선하지 않습니다.
- 연결재무제표(CFS)만 조회합니다. 별도재무제표로 자동 전환하지 않습니다. 공시 목록과 재무제표의 접수번호·기업·연도·보고서 코드가 다르면 사용하지 않습니다.
- 원화 손익계산서의 매출·영업이익, 전년 동기 변화율, 영업이익률과 변화 폭(%p)을 계산합니다. 계정이 중복되거나 통화가 다르면 해당 항목을 계산하지 않습니다.
- 분기·반기의 `thstrm_amount`는 3개월, `thstrm_add_amount`는 누적 금액입니다. 각각 `frmtrm_q_amount`, `frmtrm_add_amount`와 비교합니다. 사업보고서는 연간 값이며 독립된 4분기 값으로 간주하지 않습니다.
- 전년 값이 0 이하이면 일반적인 증가율을 계산하지 않습니다. 영업손익의 흑자·적자 전환은 별도 항목으로 표시합니다.

## 뉴스와 매매 판단 연결

뉴스 분석 후, 매매 점수 계산 전에 DART 대조를 실행합니다.

1. 기존 뉴스 규칙이 추출한 매출 변화율에 대해서만 수치를 대조합니다.
2. 제목에 연결 기준, 연도, 분기 또는 연간, 전년 동기 비교가 명시되어야 합니다. 예: `Samsung Electronics consolidated Q3 2026 revenue grew 10% YoY`.
3. 누적(YTD) 표기가 있으면 누적 수치끼리 비교합니다. 기간·기준이 다르거나 불명확하면 `unverifiable`로 남기고 기존 뉴스 정책을 유지합니다.
4. 공시 변화율과 차이가 1%p 이내이면 `consistent`, 그보다 크면 `contradicted`로 기록합니다. 이는 해당 수치의 대조 결과이며 기사 전체의 진실성·수익률 검증이 아닙니다.
5. 불일치 기사는 해당 기사의 점수 기여를 제거하고 출처 수 조건과 점수를 다시 계산합니다. 같은 기사는 LLM 입력에서도 제외합니다. 일치해도 추가 점수를 주지 않아 같은 사실을 이중 반영하지 않습니다.

재무 수치와 검증 결과는 기존 SQLite `policy_decisions` 기록에 함께 저장합니다. `app.news_explain.explain(..., dart_report=기록된_공시)`로 기사 제거 전후 비교에도 동일한 공시 자료를 적용할 수 있습니다.

## 제한 및 검증

- 현재 시점 조회용입니다. 정정 전 공시를 복원하지 않으므로 과거 시점 백테스트 자료로 사용하지 않습니다. 수집 시각이 미래이거나 24시간보다 오래된 자료, 접수일이 미래이거나 180일보다 오래된 재무정보는 뉴스 대조에서 제외합니다.
- 공시 제목의 자사주·증자 등 단어를 자동 호재·악재 점수로 바꾸지 않습니다. 실적 컨센서스 대비 초과 여부, 기업가치 평가, 실시간 공시 전달 지연은 판단하지 않습니다.
- 동일 키와 SQLite 파일에 대한 로컬 일일 예산만 관리합니다. 계정 전체의 서버 사용량은 아닙니다. 만료된 캐시는 장애 시 대체 사용하지 않으며 자동 재시도 없이 오류 후 호출을 잠시 중단합니다.
- 인증키가 없으면 실제 인증 API 성공 여부는 확인할 수 없습니다. 테스트는 모의 응답으로 계산·정정공시·캐시·오류·판단 연결을 검증합니다.
