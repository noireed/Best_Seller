# 검색·경제사건을 연결한 판단

## 실행 순서

1. 기존 EMA20·EMA50, RSI14, 20봉 모멘텀으로 가격 신호를 계산합니다. 이 숫자는 교실 전략의 설정이며 저명 투자자의 검증된 공식이라고 주장하지 않습니다.
2. 기본 모드에서는 40종목 각각의 공개 Google News RSS에서 최근 48시간의 원래 제목·발행 시각·매체를 수집합니다. 기사 본문이나 유료 Google Search grounding을 읽었다고 간주하지 않습니다. DART의 유효한 재무 수치도 별도의 공식 근거 문장으로 구성합니다. 출처에 연결되지 않은 모델 답변은 사용하지 않습니다.
3. 기존 DART 재무자료에 당일 전체 공시 목록을 추가합니다. 정기보고서 A 유형만 조회하던 경로와 달리 당일 조회는 공시 유형을 제한하지 않습니다. 시장 전체 목록을 회차당 한 번 페이지 끝까지 읽고 기업 코드로 귀속합니다. 제목만으로 호재·악재를 확정하지 않습니다.
4. 매수 후보와 보유 종목에 가격 신호, 검색 근거, 재무자료, 당일 공시, 과거 사건 결과를 전달해 Gemini의 의견과 반대 논거를 받습니다. 검색 공급자가 해당 문장에 연결한 출처만 인용할 수 있습니다. 모델이 출처 번호를 임의로 만들어 승인할 수 없습니다.
5. BUY는 명시적인 PASS와 유효한 근거가 있어야 진행합니다. HOLD·출처 미확인·통신 오류·예산 소진은 매수 승인이 아닙니다. 가격 규칙의 SELL은 긍정 뉴스와 모델 의견으로 취소하지 않습니다.
6. 가격 HOLD인 보유 종목의 경제사건 EXIT는 사건일이 당일·전일이고, 선택한 근거 문장이 서로 다른 출처 그룹 두 개 이상에 연결되며, 해당 기업에 직접 귀속되는 확정 부정 사건이 별도 규칙에서도 추출될 때만 허용합니다. 기사 전재가 서로 다른 도메인에 실릴 수 있어 출처 그룹이 독립 취재를 보장하지는 않습니다. 새로운 실험 경로이며 수익 개선이 입증된 규칙이 아닙니다.
7. 실제 주문 직전 시세와 주문 수량을 다시 계산하고 기존 현금·종목 비중·주문 금액·쿨다운·장 운영시간·미확정 주문 검사를 통과해야 합니다.

Gemini의 PASS는 투자 의견의 확인이며 주문 수량을 늘리는 명령이 아닙니다. 현재 목표 보유금액은 `min(총자산×종목 최대 비중, 총자산×(1−현금 보유비율)/감시 종목 수)`입니다. 목표를 이미 충족했거나 남은 목표 금액이 1주 가격보다 작으면 추가 매수 수량은 0입니다. 이때는 최종 행동을 HOLD로 기록하고, 별도의 `candidate_action=BUY`, `gemini_review.verdict=PASS`와 함께 목표 금액·보유 평가금액·남은 금액·제한 사유를 남깁니다. 40종목 감시 기준의 목표 배분 자체는 이번 수정에서 변경하지 않습니다.

인용 대조에서는 강조·기울임 등 Markdown 표시와 공백·HTML 문자 표기만 정규화합니다. 숫자·부호·증감 방향·부정 표현이 달라진 인용은 계속 거부합니다. 정규화로 일치한 경우 모델이 재작성한 문장을 원문처럼 저장하지 않고, 검색 공급자가 출처에 연결한 실제 근거 문장을 저장합니다. 실패 시에는 `quote_summary_mismatch`, `quote_claim_mismatch`, `invalid_claim_id` 등 구체적인 검증 사유를 기록합니다.

## 투자 원칙의 출처

- [Berkshire 1996 주주서한](https://www.berkshirehathaway.com/letters/1996.html): 이해할 수 있는 사업과 이익 창출력, 판단 가능한 범위.
- [Berkshire 1992 주주서한](https://www.berkshirehathaway.com/letters/1992.html): 사업 가치와 매수가격 사이의 안전마진. 현재 가치 산정 자료가 부족하면 적정가를 지어내지 않고 미확인으로 표시합니다.
- [IBD 매수 가이드](https://get.investors.com/wp-content/uploads/2024/08/IBDD-How-to-buy-Stocks-infographic.pdf): 전체 시장, 실적·매출·이익률, 가격·거래량을 함께 검토합니다. 부족한 입력은 미확인으로 남깁니다.

이 원칙들은 의견 검토의 정성적 질문입니다. 서로 다른 투자 철학을 하나의 검증된 전략으로 복제했다거나 같은 성과를 낼 수 있다고 해석하지 않습니다.

## 과거 사건과 주가

`examples/filing_outcomes.json`에는 2026-11-20에 현재 DART 공시 목록과 실습 서버 일봉을 대조한 40기업·273개 사례가 들어 있습니다. 공시일의 정확한 발표 시각이 없으므로 다음 거래일 시가를 기준으로 이후 1·5·20거래일 종가, 비용 후 변화, 현재 40종목 평균 대비 변화를 계산했습니다. 아직 끝나지 않은 관측 구간은 제외합니다. 실제 판단 시점 이후에 만들어진 사례와 결과도 제외합니다.

실행 중에는 이미 수집한 40종목 캔들과 공시 목록으로 사례를 갱신해 SQLite에 보존하고 다음 회차부터 전달합니다. 정정된 현재 공시 목록, 현재 감시 종목 선택 편향, 주가 수정 여부 미검증이라는 한계가 있습니다. 사건 방향별 인과효과·당시 알 수 있던 재무정보·역사적 Gemini 의견을 복원한 자료는 아닙니다. 같은 시점의 관측 사례가 많아도 독립적인 확률 표본으로 간주하지 않습니다.

## 수수료 포함 추가 매수 비교

현재 감시 40종목의 완료된 일봉으로 신호를 계산하고 다음 세션 시가에 체결시켰습니다. 초기 자금 5,000만 원, 실시간과 동일한 주문 수량 함수, 매수·매도 수수료 각 0.015%, 매도세 0.20%를 원 단위 절사했습니다. 평가 종료 시에는 강제 매도하지 않고 종가로 평가했습니다.

학습 구간은 2023-01-05~2025-08-04(629거래일), 뒤의 확인 구간은 2025-08-05~2026-11-19(315거래일)로 분리했습니다. 학습 구간 비용 후 평가금액과 최대 낙폭이 모두 기존 이상인 후보만 선택하고, 확인 구간 및 편도 5bp 슬리피지 가정에서도 우수해야 적용하도록 했습니다.

| 목표 비중 부족분에 따른 추가 매수 제한 | 학습 비용 후 수익 | 최대 낙폭 | 추가 매수 횟수 |
| --- | ---: | ---: | ---: |
| 없음, 기존 | +2.7827% | 13.5814% | 131 |
| 5% 미만 제한 | +2.7582% | 13.5728% | 81 |
| 10% 미만 제한 | +2.6419% | 13.4825% | 32 |
| 20% 미만 제한 | +2.6353% | 13.3857% | 8 |

수익과 낙폭을 함께 개선한 후보가 없어 `REBALANCE_BAND_PCT=0`을 유지했습니다. 확인 구간에서 기존 전략의 비용 후 수익은 +30.1499%, 5bp 스트레스에서는 +27.0344%였습니다. 전체 944거래일에서는 +33.0582%, 최대 낙폭 14.0616%, 거래 비용 2,227,972원이었습니다. 같은 기간 단순 보유는 +101.1467%, 최대 낙폭 40.7513%였습니다. 수익과 위험의 관계가 다르며 기존 전략이 단순 보유보다 우수하다는 결과가 아닙니다.

이 비교에는 당시의 뉴스·공시 내용과 Gemini 의견이 없습니다. 매도 보호와 검색 기반 판단의 수익률 개선은 별도 검증이 필요합니다. 현재 뉴스나 완성된 미래 사례를 과거 매매에 넣지 않습니다. 일봉 실험이며 15분 실행·호가·시장충격을 재현하지 않습니다. 5bp는 측정값이 아닌 스트레스 가정입니다. 숫자와 데이터 해시는 `examples/strategy_comparison_20261120.json`에 있습니다.

```bash
python -m app.strategy_comparison candles.json --as-of 2026-11-20T00:00:00+09:00 --output data/comparison.json
```

## 인증·운영

- 기본 `GEMINI_BACKEND=developer`는 일반 Gemini Developer API를 사용하며 `googleSearch` 등 도구가 포함된 요청을 코드에서 차단합니다. 교육용 크레딧이 소진된 유료 Agent Platform 경로로 자동 전환하지 않습니다. `vertex`는 별도의 명시 설정이 있는 경우에만 사용합니다.
- 일반 API의 무료 한도는 계정·모델에 따라 달라집니다. 로컬 기본 예산은 하루 100회, 회차당 최대 8개 의견이며 보유 종목을 먼저 검토합니다. 요청 간 최소 12초를 두고 근거·의견은 900초 동안 재사용합니다. 실제 공급자 한도가 더 작으면 그 한도를 존중하며 실패를 매수 승인으로 취급하지 않습니다. 이 코드는 결제 계정을 추가하거나 충전하지 않습니다.
- 호출 전에 소규모 슬롯을 예약해 중단 후에도 사용량이 초기화되지 않게 합니다. 정상 회차 종료 시 실제 시도하지 않은 예약만 반환하며, 통신 실패로 시도된 요청은 반환하지 않습니다. 중단된 회차의 남은 예약은 보수적으로 유지합니다. 다른 프로그램의 사용량은 포함하지 않습니다.
- 기본 `GEMINI_REQUIRED_FOR_BUY=true`, `PROTECT_SELL_SIGNAL=true`입니다. 키·한도·근거·검토가 부족하면 신규 매수를 보류합니다. 가격 기준 매도는 긍정 뉴스나 모델 오류로 취소하지 않습니다. RSS가 비어 있어도 신선한 DART 재무 근거가 있다면 해당 공식 수치로 검토할 수 있으며, RSS 조회 상태는 별도로 기록합니다.
- [Gemini 요금 안내](https://ai.google.dev/gemini-api/docs/pricing)와 [계정별 한도 안내](https://ai.google.dev/gemini-api/docs/rate-limits)를 참고하세요. 무료 일반 분석을 Google 검색 기능의 무료 사용으로 해석하면 안 됩니다. RSS는 기사 제목 메타데이터이며 발행일이 실제 사건 발생일을 보장하지 않습니다. 동일 기사의 전재도 있을 수 있으므로 매체 그룹 수를 독립 검증의 증거로 간주하지 않습니다.
- 기존 야간 대기·후속 실행 예약·미확정 주문 대사 구조를 유지합니다. 상태 파일에는 Gemini 사용량·근거·과거 사례·당일 공시 캐시도 보존합니다.


## 주문 통신 실패 후 재개

주문 통신 오류를 서버 거절이나 체결로 간주하지 않습니다. 전체 서버 주문 이력에서 유일한 일치 체결·취소를 확인하면 해당 결과를 반영합니다. 일치 내역이 없으면 다음 조건을 모두 만족해야 `NO_SERVER_ORDER_OBSERVED`라는 별도 관측 결과로 정리합니다.

- 요청 후 최소 10분 경과, 모든 페이지 조회, 중복 주문 ID 없음, 기존에 기록한 서버 주문들이 이력에서 사라지지 않음.
- 해당 종목에 요청 이후 다른 주문이나 OPEN·PARTIAL 주문이 없음.
- 주문 전 보유 수량과 현재 보유·가용 수량이 정확히 같음. 이전 BUY 기록은 저장된 평가금액과 가격에서 정확한 정수 수량을 복원할 수 있을 때만 사용함.
- 최소 60초 간격의 두 독립 조회에서 전체 주문 이력 해시와 해당 종목 보유·가용 수량이 일치함.

이 결과는 서버의 명시적 거절 응답이나 체결 기록을 만들어내는 것이 아닙니다. 원래 요청과 통신 오류·두 관측 시각·이력 해시를 보존하고 원주문은 재전송하지 않습니다. 이후 주문은 새 시세·계좌·뉴스 검토에 따른 별도 판단입니다. 계좌가 변했거나 이력이 불완전·모호하면 계속 보류하며, 확인 대기 중에도 40종목 조사와 판단 기록은 갱신합니다. API가 지연된 데이터를 제공할 가능성까지 수학적으로 배제하는 장치는 아닙니다.

정기 재무자료가 없거나 오래되면 주문 회차에서 DART를 직접 조회합니다. 유효한 기업코드 캐시만 연구 작업에서 재사용하며 원래 관측·만료 시각을 연장하지 않습니다. 모델이 근거 문장 번호만 잘못 지정한 경우, 인용문이 검색 공급자의 다른 근거 문장 하나와 유일하게 일치할 때만 해당 문장·출처로 연결을 바로잡습니다. 여러 후보가 있거나 내용이 달라지면 보류합니다.
